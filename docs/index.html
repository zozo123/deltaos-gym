Linux systems tasks

Six coding exercises for Linux and eBPF. Each asks for one change and specifies the behavior your code must preserve.

Tasks

  • Allow one connectionLet one user reach a specific address and port over TCP. Preserve every other network rule.
  • Enforce a quotaReject charges that exceed the budget or overflow the total. A rejected charge must leave both counters unchanged.
  • Detect an overflowFlag exactly the inputs that overflow an 8-bit calculation in Linux IPv6 routing code.
  • Replace a file safelyAfter a crash, readers must see either the complete old file or the complete new one.
  • Launch a workerPass only the authorized file handle. Wait for the worker even if a signal interrupts the wait, and report failure if the worker fails.
  • Diagnose a failing serviceChoose the cheapest set of measurements that distinguishes every possible cause within the budget and probe limit.

Run a task

With Docker and Harbor installed, run the reference solution for the file replacement task.

git clone https://github.com/zozo123/deltaos-gym
cd deltaos-gym
harbor run -p tasks/vfs-crash-atomicity -a oracle

Grader results

On Linux 7.1.4, the graders rejected all 71 known incorrect solutions across 355 runs. They accepted correct alternative implementations in 85 of 85 runs.

Each run records which checks passed. Depending on the task, these include Linux tests, simulated crashes, or proofs over a stated model.
